Storage summary

Backup

Exports every venue, roster, radio, accessory and sign-in record as a single JSON file. Worth running before any significant change.

Pre-events archive

Data from before ONsite organised work by event — rosters, radio and accessory stock, and sign-in history that were tied directly to a venue. Venues, users and dropdown lists were not affected.

Retention

Sign-in records are personal data. Keeping them indefinitely is hard to justify under UK GDPR, so purge closed records once you no longer need them. Anyone still signed in is never deleted.

Delete completed records older than

Delete an Event

Permanently removes an event and everything tied to it — roster, radio and accessory stock, and its sign-in and radio history. This is different from removing an event while switching venues, which keeps sign-in history. There is no undo; export a backup first if you might need this later.

Factory Reset

Permanently deletes every venue, event, crew roster, radio, accessory, sign-in record and radio history entry — for everyone, on every device connected to this database. Not just this device: the shared cloud database itself is wiped. User accounts, invites and dropdown lists are not affected, so nobody is locked out.

There is no undo. Export a full backup first if there is any chance you'll want this data again.

This device is running in local-only mode. Factory reset needs an active connection to the shared database, since it wipes that database, not just this device.
